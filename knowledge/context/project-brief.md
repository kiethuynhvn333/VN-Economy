# Project brief

## Question

What capabilities and industry clusters should Viet Nam build over the long run to raise
productivity, income, and resilience rather than relying mainly on cheap labour, land, consumption,
or low-value FDI assembly?

## Product goal

Build an evidence-backed interactive map that shows:

- foundational capabilities;
- mechanisms that connect capabilities to industry outcomes;
- constraints and feedback loops;
- what is measured, inferred, hypothesized, or still unknown.

## Research rules

The project is exploratory. A source can suggest a direction without proving it. The system must
preserve competing explanations, source quality, time period, and missing data.
