# Structured registries

These TSV files are the future input to search, QA, and visualization tools. Keep IDs stable.

- `sources.tsv`: one row per imported source.
- `claims.tsv`: one row per atomic claim.
- `edges.tsv`: one row per reviewed relationship.

Do not put long prose in the registries. Link to the source file and keep explanations in the
human-readable research notes.
